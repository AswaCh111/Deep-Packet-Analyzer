DeepTrace API v2.4
The DeepTrace REST API provides programmatic access to Deep Packet Inspection, real-time network traffic analysis, threat intelligence lookups, and automated incident response capabilities.

Base URL: https://api.deeptrace.io/v2
✅
API Status: OPERATIONAL — All Systems Normal — Latency 12ms
bash # Quick start — analyze a packet curl -X POST https://api.deeptrace.io/v2/analyze \ -H "Authorization: Bearer dt_live_your_api_key" \ -H "Content-Type: application/json" \ -d '{"src_ip":"192.168.1.44","dst_ip":"185.220.101.8","protocol":"DNS","dst_port":53}'
Authentication
All API requests require a Bearer token in the Authorization header.
